## 功能改动点

- 将「权限与安全」总览页从纯文字堆砌重构为「真实授权状态驱动」的卡片式布局：用户一进来即可看到「管理数字员工能碰什么——不授权，就不能执行」的明确职责声明，以及当前授权边界的真实状态徽章。
- 新增「授权边界」三张领域卡片（目录访问 / 网站访问 / 风险动作）：每张卡片展示当前配置状态徽章（已启用·模式 / 未配置 / 已关闭）、摘要计数（N 个允许目录、N 个拦截站点等）、可展开的详情条目，以及「去配置 / 管理授权」主操作按钮——未配置项以强调色 CTA 引导用户直接进入配置。
- 新增「相关入口」三张快捷卡片（审计记录 / 账号授权 / 企业中枢），点击直接切换到对应分区，替代原来的静态文字说明。
- 新增「去配置」锚点跳转交互：总览卡片点击后自动切换到「授权配置」分区，并通过 hash 锚点（`security-directory` / `security-website` / `security-risk`）让配置页平滑滚动定位到具体授权区块；切出总览时自动清理锚点，避免再次进入时误滚动。
- 授权状态读取基于真实配置：通过 `/api/hermes-config` 的 `security` 段解析目录 / 站点 / 风险动作规则，15s 内复用缓存、30s 自动轮询刷新，页面状态与底层配置保持同步。
- 保留全部既有稳定 `data-testid`（`security_center_page` / `security_center_tab_*` / `security_center_panel_*`），既有 E2E 归并与配置用例不受影响。

## 风险点 / 遗留事项

- 总览状态依赖 `/api/hermes-config` 的 `security` 段字段结构，若后续配置模型字段更名需同步调整 `useSecurityStatus` 解析。
- 锚点滚动依赖 `HermesConfigSection` 数据就绪后执行（120ms 延时），在极慢配置加载场景下定位可能略有偏差；已通过 `hashchange` 监听兜底，用户手动重触发可再次定位。
