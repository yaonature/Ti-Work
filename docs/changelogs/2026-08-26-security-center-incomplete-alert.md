## 背景 / 问题

上一版在「权限与安全」顶部保留了 Hero 区（标题「管理数字员工能碰什么」+ 大段说明 + 安全状态徽标）。

用户反馈：该 Hero 与下方「授权配置」Tab 内的 `目录 / 网站 / 风险动作 / 安全与工具` 四个配置区块内容重复，属冗余信息，观感罗嗦；应仅保留「授权尚未配置」提醒，并做成**可点击**，点击后能明显看出是哪几项未配置。同时要求交互从用户视角出发，所见即明白，禁止在按钮上长篇文字解释。

## 功能改动点

- **移除冗余 Hero 模块**：删除 `audit.tsx` 顶部 `security_center_hero` 卡片（大标题、说明文字、「本地治理 · 云端真相」标签、状态徽标），避免与下方授权配置区块重复。
- **新增极简「未配置提醒」条**：仅在存在未配置项（`未配置领域数量 > 0`）时展示，单行条列出各项未配置领域，可**逐项点击**直达对应配置区块。
  - 每条未配置项为独立胶囊按钮（`目录访问 / 网站访问 / 风险动作`），带 `↗` 图标示意可跳转。
  - 点击某项 → `goConfigure(anchor)` → 切到「授权配置」Tab 并通过 hash 定位到对应配置块。
- **从用户视角的交互**：用户进来第一眼只看到「有几项未配置 + 逐项跳转入口」，无需阅读说明文字即可直达配置；配置齐全时提醒条自动隐藏，页面仅剩 Tab 与配置内容。
- **清理无用 import**：删除 Hero 后不再使用的 `Shield01Icon`、`LockIcon` 图标引用。
- **极简 Tab（后续确认）**：去掉 5 个 Tab 按钮下的副标题说明文字，Tab 仅保留标签（`总览 / 授权配置 / 审计记录 / 账号授权 / 企业中枢`）；同步移除内容区标题下方的描述行与 `SECURITY_TABS` 的 `description` 字段。
- **精简总览（后续确认）**：删除「总览」Tab 内与「授权配置」重复的 `授权边界` 三张去配置卡（目录访问 / 网站访问 / 风险动作）及大标题说明，仅保留 `相关入口` 快捷卡；`相关入口` 卡片去掉描述文字，只留图标 + 标签（`审计记录 / 账号授权 / 企业中枢`）。
- **组件与引用清理**：删除不再使用的 `DomainCard`、`TagList`、`StatusBadge`、`BadgeTone`、`RISK_ACTION_LABELS`、`directoryModeLabel`、`websiteModeLabel` 及 `Folder01Icon`、`GlobeIcon`、`CheckmarkCircle01Icon`、`Clock01Icon` 图标引用。

## 测试要点

- 未配置项存在时（`directory` / `website` / `risk` 任一未配置），顶部展示「有 N 项授权尚未配置」提醒条，N 为未配置领域数量。
- 点击某未配置胶囊（如「目录访问」）→ 切换到「授权配置」Tab 并定位到对应配置块。
- 全部配置齐全时，提醒条隐藏；Tab 切换与授权配置不受影响。
- `pnpm build` 全链路（client + SSR）通过。
- E2E 新增用例 `UI-DESK-PERM-0002`：`security_center_merge.spec.ts` 构造三项未配置状态，断言提醒条出现且提示数量正确，点击「网站访问」「风险动作」分别定位到对应子 Tab。

## 风险点 / 遗留事项

- 通用审批链正式接入执行链路仍为独立待办（见基线清单 3.3）。
