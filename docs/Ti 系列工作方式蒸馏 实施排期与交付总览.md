## 2. 实施阶段与里程碑（排期主视图）

> 阶段划分只依据依赖关系与可并行性，不含时间估算。

**Stage 0｜L1 个人沉淀闭环（可立即启动，零外部依赖）**
- 工作项：W-D6；前置：无（数据源 P1-A/P1-B 已上线，与共创 Gate 完全解耦）。
- 退出条件（M1）：非共创账号（默认态）完整走通"提示 → 预览 → 固化 → 技能页可删"闭环；频控符合 v1 参数；D1-D5 采集目录零数据。

**Stage 1｜L2 采集底座（桌面，关键路径起点）**
- 工作项：W-D1（第一前置）→ W-D2、W-D3（可并行）；前置：W-D1 开工前需收口 §5 决议第 1 组。
- 退出条件（M2a）：D1 交付物登记 + 脱敏可用（授权生效时自动采集、默认态零数据）；D2/D3 样本可生成且断言不落原文；`npm test` 全绿、既有链路零回归。

**Stage 2｜样本可见与授权收口（桌面）**
- 工作项：W-D4 → W-D5；前置：W-D1-D3 完成；W-D4 开工前需收口入口位置决议。
- 退出条件（M2b）：D4 档案页可查看/筛选/一键清理且入口克制；D5 授权状态视图可用（本地无"常开采集"入口）、会话内确认按决议落地；全量测试绿 + 勾选清单回填。

**Stage 3｜账号通道（桌面 ↔ 云端连接件）**
- 工作项：W-U1（6.6.11-U 网络登录改造批客户端侧）；前置：与 W-C1/W-C4/W-C5 的契约字段冻结（云端蓝图 §4 契约表）；云端接口未就绪时以本地配置模拟授权过渡（不阻塞 Stage 1/2 的工程实施）。
- 退出条件（M3）：真实账号判定生效——共创授权拉取、资产下发接收、跑测反馈回传三通道可用，替代本地模拟。

**Stage 4｜云端一期最小闭环（Ti Work 云端管理端 + OPC 治理点）**
- 工作项：W-C1 → W-C2 → W-C3 → W-C4 → W-C6 → W-C5（W-C7 复用不开发）；W-P1 并行（OPC 审核位 + 权益清单模拟）。
- 前置：W-C1 开工前需收口 §5 决议第 2 组；Stage 1-3 就绪。
- 退出条件（M4，首案交付口径）：一条业务线跑通"共创账号回传 → 加工出 candidate → 管理员下发 → 验收账号本机真机试跑 → 反馈迭代 → OPC 审核通过 → 权益制放行分发"全链路；该业务线验收达"与本人交付一致"阈值（阈值口径见 §5 决议第 3 组）。

**Stage 5｜规模化（二期，首案不排）**
- 真实计费与分成、C3 常驻蒸馏 job 与模型化、C4 试跑记录自动聚合、C1 自动分层邀请与质量打分、C6 自动巡检。

## 4. 关键路径与并行关系

- **关键路径（L2 主线）**：W-D1 → W-D2 / W-D3 → W-D4 → W-D5，与云端 W-C1 → W-C2 → W-C3 → W-C4 → W-C6 → W-C5 通过 W-U1 衔接，终点为 M4（首案全链路）。
- **可并行的独立线**：Stage 0（W-D6）与全部其它工作项无依赖，可最先启动且不阻塞；W-P1 / W-P2 为平台平行线；W-C3 人工起草形态不依赖 W-P2 就绪（能力接口可后置接入）。
- **连接件唯一**：桌面与云端的所有数据交换仅经云端蓝图 §4 四张契约（样本回传 / 共创授权 / 权益判定 / 资产下发 / 跑测反馈），契约字段冻结是 W-U1 与 Stage 4 的共同前置。
- **最短可用链路**：若只追求"桌面自证"价值，Stage 0 + Stage 1 + Stage 2（M1 + M2b）即可独立交付，不依赖任何云端能力。

## 5. 开工前必须收口的决议（阻塞映射）

> "必答"= 不决议则无法按最佳实践实现；"可收敛"= 可先按草案参数实施，用真实样本校准。

**组 1（阻塞 Stage 1/2 桌面）**
- 首案交付物类型与文件 kind 白名单（先通用 docx/pdf/md/txt/xlsx）——必答（W-D1）；
- 共创授权过渡实现形态与安全边界（本地模拟防普通用户自行开启）——必答（W-D1）；
- 脱敏规则词表来源（内置 v0 + 首案扩充）——可收敛（W-D1）；
- D3 配对启发式阈值（时间窗 / 文件名族相似度）——可收敛（W-D3）；
- D4 工作台入口位置与导航收口方式——必答（W-D4）；
- 是否将"会话内二次确认"纳入首案——必答（W-D5）。

**组 2（阻塞阶段 4 前半：W-C1/W-C3）**
- 分层验证制实操口径（资质核验、L2 度量门槛、修订链稀疏阈值、同行背书来源）——必答；
- L1 规范资产 Schema 与 Skill 规范资产包结构定稿——必答；
- 蒸馏触发节奏（一期手动攒批阈值）——可收敛；
- L2 规则学习一期达到的半自动程度——可收敛。

**组 3（阻塞阶段 4 后半：W-C4/W-C5/W-C6）**
- 下发名单最小配置模型与跑测记录字段定稿——必答；
- 内测名单与正式权益包的授权策略边界（吊销/宽限差异）——必答；
- Skill 资产分发与计费口径（订阅/按件、企业批量、离线宽限、试点定价）——必答；
- 素材授权模型（个人 / 企业 / 客户知情同意）——必答；
- 首案人工复核（管理员 + 权威第二人）留痕最小形态——可收敛；
- 资产包 Schema 版本协商流程——可收敛。

**组 4（阻塞 Stage 0：W-D6）**
- 提示默认参数（≥5 次 / 跨 ≥2 天 / 周 ≤2）与文案字段驱动来源——可收敛（按画像真实样本校准）；
- 提示时机与入口收口（会话收口空闲小窗 vs 工作台候选清单的协同、疲劳上限）——必答；
- personal 分类与 `skills.ts` `KNOWN_CATEGORIES` 的兼容方式——必答。

**组 5（阻塞 M4 验收口径）**
- L2 基线度量口径（同主题比对如何不沉淀原文、人工改动量统计）——必答；
- 影子比对准入与分级放行判据——必答；
- "与本人交付一致"阈值（专家复核通过率 + 人工改动量）——必答；
- 第 6 章 / 第 8 章其余业务前置（所方切面清单、首批对齐样本库、执业复核点更新机制）——业务侧并行推进，不阻塞工程启动。

## 6. 每工作项收口口径（统一纪律）

1. 新增模块与"只读消费者"优先：`distill` 相关改动**零改动**既有事件流 / `habit-sequences` / `agent-run-sediment` / run-ledger B2 / P1-B；写盘失败静默（沿用 P1-A 纪律）；
2. 每工作项产出 `docs/changelogs/` 改动说明 + `src/test` 测试脚本，`npm test` 全绿后收口；
3. 完成项回填《Ti 系列统一开发基线勾选清单.md》；
4. 注释中文；commit 按功能分批、由用户授权后执行（禁止私自提交）；
5. 文档同步：实现与文档冲突时，先改源文档（评审稿 / 对应蓝图）再动代码。

## 7. 首案明确不做（防止排期误纳）

- 二期项：真实计费与分成、常驻蒸馏 job、自动巡检、自动分层邀请与质量打分、试跑记录自动聚合、Workflow 云端编排运行；
- 红线永不建：云端执行用户真实任务、云沙箱、云端持有真实交付正文；
- L1 不涉云：D6 个人 Skill 不上云、不引导共创、无 L2 采集。
